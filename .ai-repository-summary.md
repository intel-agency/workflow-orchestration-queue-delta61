## Repository Summary: workflow-orchestration-queue-delta61

### Project Overview

**workflow-orchestration-queue (OS-APOW)** is a headless agentic orchestration platform that transforms GitHub Issues into automated Execution Orders. It enables autonomous AI-driven development by polling for tasks, claiming them, and dispatching workers in isolated DevContainers.

### Key Components

1. **Sentinel Orchestrator** (`src/orchestrator_sentinel.py`)
   - Persistent background service polling for tasks
   - Implements assign-then-verify locking pattern
   - Posts heartbeat comments during long-running tasks

2. **Notifier Service** (`src/notifier_service.py`)
   - FastAPI webhook receiver for GitHub events
   - HMAC SHA256 signature validation
   - Event triaging and task queueing

3. **GitHub Queue** (`src/queue/github_queue.py`)
   - GitHub Issues-based task queue
   - Connection pooling with httpx
   - Status management via labels

4. **Work Item Model** (`src/models/work_item.py`)
   - Unified task representation
   - Secret scrubbing utility
   - Provider-agnostic interface

### Labels

Key labels used for state management:

- `agent:queued` - Task awaiting processing
- `agent:in-progress` - Task being processed
- `agent:success` - Task completed successfully
- `agent:error` - Task failed
- `orchestration:plan-approved` - Plan ready for epic creation

### Development Workflow

1. Create issue with appropriate template
2. Apply `orchestration:dispatch` label to trigger orchestration
3. Sentinel picks up task and dispatches worker
4. Worker creates PR with changes
5. Review and merge
